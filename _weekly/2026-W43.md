# AI 研发工作流周刊 2026-W43

## 代码 / IDE

- **[Qwen Code Desktop v0.26.1](https://github.com/QwenLM/qwen-code/releases/tag/desktop-v0.26.1)** — 阿里 Qwen Code · 2026-10-25
  阿里 Qwen Code 发布 Qwen Code Desktop v0.26.1，新增 serve 守护进程令牌持久化、managed-agent 手动上下文压缩与会话生命周期 UI 及读取导出，并让 CLI 的 OpenTUI 输入、编辑与状态行对齐 Ink。修复方面包括目录变更后的误中断、release 打包可执行位校验、web-shell 技能安装错误提示等，另有多项测试与 CI 调整。
- **[Devin Desktop / Windsurf v3.11.216](https://docs.devin.ai/desktop/changelog#v3-11-216)** — Windsurf · 2026-10-24
  Windsurf 发布 v3.11.216（2026-10-24），修复了无 Devin Cloud 会话权限的成员无法查看、打开和启动 Devin Local 会话的问题。Windows 上安装 Devin CLI 后无需先退出登录即可在新的终端中使用 devin；macOS 和 Linux 上重复运行安装命令会刷新链接而非失败。此外还修复了终端输出内联图片时 Devin Local 会话崩溃的问题。
- **[Release v0.26.1](https://github.com/QwenLM/qwen-code/releases/tag/v0.26.1)** — 阿里 Qwen Code · 2026-10-24
  阿里 Qwen Code 发布 v0.26.1，包含一项破坏性变更：修复 qqbot 在线程作用域下按群组恢复会话隔离。新功能包括守护进程令牌持久化（--save-token 保存、token 子命令管理、stop 时移除）、Workspace 绑定 Managed Sessions 的空闲时手动上下文压缩，以及 OpenTUI 输入、编辑、草稿与 /statusline 行为对齐 Ink 等。
- **[Usage metrics API adds usage from tools like OpenCode](https://github.blog/changelog/2026-10-23-usage-metrics-api-adds-usage-from-tools-like-opencode)** — GitHub Copilot · 2026-10-24
  GitHub Copilot 的用量指标 API 现在会报告更多工具（包括此前未被统计的 OpenCode 等）的模型使用情况，并在企业、组织及对应用户的 1 天和 28 天报告中新增 totals_by_client 数组。每个条目包含客户端、请求数、会话数、token 用量及按模型细分的数据，用于统计来自任何使用 Copilot 的工具的模型流量。该变更为增量式，现有字段不变，无用量时该数组为空。
- **[Turn notifications into code with GitHub Copilot in Teams](https://github.blog/changelog/2026-10-23-turn-notifications-into-code-with-github-copilot-in-teams)** — GitHub Copilot · 2026-10-24
  GitHub 在 Teams 中推出新版 GitHub 应用，将通知与 Copilot 结合，用户可在频道、群聊或私聊中收到通知后 @mention GitHub，把 issue 通知转为拉取请求。该应用前身为 GitHub notifications，已安装用户需更新至最新版本，原有通知功能继续可用。旧版 GitHub 应用将更名为“GitHub (deprecated)”并于 11 月 16 日停用，用户需安装整合版应用以继续在 Teams 中使用 Copilot。
- **[v2.1.310](https://github.com/anthropics/claude-code/releases/tag/v2.1.310)** — Anthropic Claude Code · 2026-10-24
  Anthropic Claude Code 发布 v2.1.310，新增 Monitor 工具及插件监控，并修复网关兼容、后台清理误删近期文件、压缩后请求失败等问题。该版本还改进了非交互会话的内存占用与沙箱提示，并为云会话、Claude Tag 和代码审查修复多项界面与权限问题。
- **[0.164.0](https://github.com/openai/codex/releases/tag/rust-v0.164.0)** — OpenAI Codex · 2026-10-23
  OpenAI Codex 发布 0.164.0，新增十个编号 `/presets` 槽位保存可复用提示词与斜杠命令，并支持通过内联 `/model`、`/permissions` 参数直接设置模型、推理强度、速度与权限配置。该版本还支持在 Kitty 或 Sixel 图形终端中全屏预览图像、使用 Codex 账户授权或专用登录认证企业 MCP 连接，并在受支持的远程 Bash 命令与 Zsh 快照会话中遮蔽凭据；Amazon Bedrock 设置向导默认启用。修复方面包括压缩失败不再残留部分摘要、恢复会话可找到压缩历史并还原线程设置、Windows 代理认证处理等。
- **[Custom skills, agents, and MCP servers in usage metrics API](https://github.blog/changelog/2026-10-22-custom-skills-agents-and-mcp-servers-in-usage-metrics-api)** — GitHub Copilot · 2026-10-23
  GitHub Copilot 用量指标 API 现在会显示组织自定义的 skills、custom agents、MCP servers、slash commands 和 plugins 的名称，不再将其归入 other 或 custom。企业及组织报告中各 totals_by_* 列表每条记录最多可包含 25 个条目（此前为 5 个），剩余活动合并到末尾的 other 条目，interaction_count 与 distinct_*_use_count 字段的计算方式不变。名称来自 Copilot CLI、GitHub Copilot 应用、ACP 集成及 Copilot SDK 等客户端遥测，部分客户端需满足最低版本要求，且指标可能低估活动。
- **[GitHub Copilot in Visual Studio — September update](https://github.blog/changelog/2026-10-22-github-copilot-in-visual-studio-september-update-2)** — GitHub Copilot · 2026-10-23
  GitHub Copilot 在 Visual Studio 的九月更新中，Git 代理现可探索拉取请求，在 Copilot Chat 中附加拉取请求作为上下文即可获得摘要及指向评论和文件的可导航链接，该功能需连接 Git 提供商的 MCP 服务器，支持 GitHub 和 Azure DevOps。Bring Your Own Model（BYOM）处于预览阶段，在 Community、Professional 和 Enterprise 版本中默认开启，但现需配合基于 GitHub Copilot SDK 的新 Agent（预览）使用，原有 Ask 和 Agent 模式不再支持 BYOM，更新后需重新添加此前配置的 Ollama 模型。此外，Error List 中的 NuGet Audit 警告新增修复操作，可打开 Copilot Chat 代理模式并借助 NuGet MCP 服务器修复存在漏洞的包，该更新面向所有 Copilot 计划用户。
- **[Global default for Copilot features generally available](https://github.blog/changelog/2026-10-22-global-default-for-copilot-features-generally-available)** — GitHub Copilot · 2026-10-23
  GitHub 宣布，针对 Copilot Business 和 Copilot Enterprise 计划中已正式发布的 Copilot 功能及受支持的客户端能力，其全局默认策略自 2026 年 10 月 22 日起逐步强制执行，预计持续至 10 月 26 日，不同企业或组织生效时间可能不同。未配置的符合条件功能将按所选全局默认值（启用、禁用或由组织决定）设置，这是一次性变更；管理员已明确设置的单项功能保持不变，预览功能仍需主动选择加入。
- **[v2.1.309](https://github.com/anthropics/claude-code/releases/tag/v2.1.309)** — Anthropic Claude Code · 2026-10-23

## 智能体平台

- **[Self-Hosted Orbs](https://ampcode.com/news/self-hosted-orbs)** — Sourcegraph Amp · 2026-10-22
  Sourcegraph Amp 于 2026 年 10 月 22 日发布 Self-Hosted Orbs，用户可在自有基础设施上自行托管 orbs，由自己提供算力，Amp 将其转化为 orbs。使用方式是在自有基础设施中运行 amp orb provider，由其连接 Amp 并等待创建、暂停或删除 orbs 的请求，具体操作由用户提供的程序（如 dispatch.sh）执行。原文给出了 Docker、E2B、K8s、Apple containers、Modal 等示例。
- **[Assign It To Amp](https://ampcode.com/news/assign-it-to-amp)** — Sourcegraph Amp · 2026-10-19
  Sourcegraph Amp 现已成为 Linear 中的 agent，将 issue 指派给 Amp 即可在 Linear 中启动新的 Agent Session 并生成新的 orb，也可通过 @Amp 提及来启动会话。Amp 的回复会发回同一会话，该 Agent Session 也会出现在 Amp 侧边栏并可在 Amp 中完整查看。使用前需在 Linear 工作区安装 Amp agent，并在 Settings → MCP & Integrations 中将 Amp 账户连接到 Linear MCP。
