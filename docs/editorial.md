# AI 研发工作流周刊 · 内容口径

1. **只用官方源核实**：每条事实须能追溯到 sources.yml 中的官方一手来源（changelog、GitHub releases、官方博客 RSS）。媒体报道、社交帖子、第三方汇总只作线索，不作依据。
2. **价格变化**：必须对比官方定价页（pricing_url）的前后快照（保存日期+原文），写明旧价、新价、档位、计费单位。无快照对比的不得写“涨价/降价”。
3. **月付/年付切换**：仅计费周期切换或年付折扣展示变化，只标记为“计费周期变化”，不算涨价或降价。
4. **verified 规则**：verified=false 的来源或条目一律不进周刊；来源失效（404/403/feed 为空）即置 false，复测通过后再恢复。
5. 发布说明须附原始链接与发布日期（Asia/Shanghai）；beta/预览功能须标注。
